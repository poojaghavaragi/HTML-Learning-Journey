# 🌐 Day 1 – Introduction to HTML

## 1. What is HTML?

HTML stands for **HyperText Markup Language**.

It is used to create the structure of web pages.

HTML helps us add:
- Headings
- Paragraphs
- Images
- Links
- Lists
- Tables
- Forms

## 2. Basic HTML Structure

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>I am learning HTML.</p>
</body>
</html>
```

### Important HTML Tags

| Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares HTML5 |
| `<html>` | Root element |
| `<head>` | Contains page information |
| `<title>` | Sets the browser tab title |
| `<body>` | Contains visible webpage content |
| `<h1>` to `<h6>` | Creates headings |
| `<p>` | Creates a paragraph |
| `<br>` | Adds a line break |
| `<img>` | Displays an image |

## 3. HTML Text Formatting

HTML provides different tags to format text.

| Tag | Purpose |
|---|---|
| `<b>` | Bold text |
| `<strong>` | Important text |
| `<i>` | Italic text |
| `<em>` | Emphasized text |
| `<u>` | Underlined text |
| `<mark>` | Highlights text |
| `<del>` | Shows deleted text |

### Example

```html
<h2>My Skills</h2>
<p><b>Python</b></p>
<p><i>HTML</i></p>
<p><u>Learning Web Development</u></p>
<p><mark>Practice Daily</mark></p>
```

## 4. HTML Links

The `<a>` tag is used to create hyperlinks.

### Example

```html
<a href="https://www.google.com">Visit Google</a>
```

- `<a>` – Creates a link.
- `href` – Specifies the destination address.
- Link text – Text displayed to the user.

### Open Link in a New Tab

```html
<a href="https://www.google.com" target="_blank">
Visit Google
</a>
```

`target="_blank"` opens the link in a new tab.

## 5. HTML Images

The `<img>` tag is used to add pictures to a webpage.

### Example

```html
<img src="myphoto.jpg" alt="My Picture">
```

- `img` – Displays an image.
- `src` – Specifies the image location.
- `alt` – Provides alternative text if the image cannot load.
