# 🌐 Day 2 – HTML Lists, Tables and Forms

## 1. HTML Lists

HTML lists are used to display items in an organized way.

There are two main types:

### A. Unordered List
Displays items using bullet points.

```html
<ul>
    <li>HTML</li>
    <li>Python</li>
    <li>Java</li>
</ul>
```

**Output:**
- HTML
- Python
- Java

### B. Ordered List
Displays items using numbers.

```html
<ol>
    <li>HTML</li>
    <li>Python</li>
    <li>Java</li>
</ol>
```

**Output:**
1. HTML
2. Python
3. Java

**Important tags:**

| Tag | Meaning |
|---|---|
| `<ul>` | Unordered list |
| `<ol>` | Ordered list |
| `<li>` | List item |

## 2. HTML Tables

HTML tables are used to display information in rows and columns.

### Example:

```html
<table border="1">
    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>
    <tr>
        <td>Pooja</td>
        <td>Python</td>
        <td>80</td>
    </tr>
    <tr>
        <td>Radha</td>
        <td>HTML</td>
        <td>85</td>
    </tr>
</table>
```

**Important tags:**

| Tag | Meaning |
|---|---|
| `<table>` | Creates a table |
| `<tr>` | Creates a table row |
| `<th>` | Creates a heading cell |
| `<td>` | Creates a data cell |

**Note:** `border="1"` adds a border to the table. CSS is generally preferred for styling tables.

## 3. HTML Forms

HTML forms are used to collect information from users.

Examples:
- Name
- Email
- Password
- Contact details

### Example:

```html
<h2>Contact Me</h2>

<form>
    <label>Enter your name:</label>
    <input type="text" placeholder="Your name">

    <br><br>

    <label>Enter your email:</label>
    <input type="email" placeholder="Your email">

    <br><br>

    <button type="button">Submit</button>
</form>
```

**Important tags and attributes:**

| Tag / Attribute | Meaning |
|---|---|
| `<form>` | Creates a form |
| `<label>` | Displays a label |
| `<input>` | Creates an input field |
| `type="text"` | Allows text input |
| `type="email"` | Allows email input |
| `placeholder` | Displays temporary hint text |
| `<button>` | Creates a button |
| `<br>` | Adds a line break |
